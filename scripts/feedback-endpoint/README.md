# Приёмник отзывов (Google Apps Script)

Куда приложение складывает два события: отметку «версия установлена» и текст,
написанный в карточке «Обратная связь» на экране «О программе».

Отправитель — `src/main/feedback.ts`. Без заполненного `BACKEND_URL` он молчит,
а карточка на экране «О программе» пишет, что отправка не настроена.

---

## 1. Таблица

1. Создай новую Google Таблицу.
2. Скопируй `Code.gs` в **Расширения → Apps Script** этой таблицы (файл
   `apps-script.json` менять не нужно).

## 2. Листы

В редакторе Apps Script выбери функцию `setup` и нажми **Запустить**. Она
создаст два листа — `Installs` и `Feedback` — и выведет в журнал строку вида
`SHEET_ID = '1AbC...'`. Этот id вставь в `SHEET_ID` в начале `Code.gs`
вместо `PASTE_SPREADSHEET_ID_HERE`.

Если запускаешь скрипт не из таблицы, а как отдельный проект, `setup` возьмёт
активную таблицу — тогда сначала открой её и запусти `setup` ещё раз.

## 3. Публикация

**Развернуть → Новый тип развёртывания → Веб-приложение**:

| Поле | Значение |
|---|---|
| Описание | `OCD feedback` |
| Выполнять от имени | **Меня** |
| Кто имеет доступ | **Все** (или «Все, у кого есть ссылка на Google-аккаунт») |

После развёртывания появится URL вида
`https://script.google.com/macros/s/AKfycb.../exec`. Это и есть `BACKEND_URL`.

## 4. Впиши URL в приложение

`src/main/feedback.ts`:

```ts
export const BACKEND_URL = "https://script.google.com/macros/s/AKfycb.../exec"
```

Пересобери (`npm run dist`) — URL попадает в exe на этапе сборки.

> Веб-приложение разворачивается по версии: после каждого изменения в `Code.gs`
> нужно **Управление развёртываниями → Изменить → Новая версия**, иначе
> `exec` продолжит отдавать старую.

---

## Проверка

Открыть `<url>/exec` в браузере — вернётся JSON:

```json
{ "ok": true, "uniqueInstalls": 1, "marks": 13, "perVersion": { "0.1.13": 1 }, "feedback": 0 }
```

`uniqueInstalls` — число машин, `marks` — число отправленных отметок. Разница
между ними и есть обновления: одна машина, прошедшая 13 релизов, пишет 13 строк
и считается один раз.

Проверить отправку вручную:

```bash
curl -X POST -H "content-type: application/json" \
  -d '{"app":"OCD","event":"feedback","kind":"complaint","message":"тест","version":"0.1.13","installId":"test","os":"Windows_NT 10.0.22631","arch":"x64","electron":"44.5.1","locale":"ru"}' \
  "<url>/exec"
```

---

## Что уходит и что нет

| Поле | Когда | Что это |
|---|---|---|
| `installId` | всегда | случайный UUID в `%APPDATA%\OCD\ocd-feedback.json`; отличает одну машину от другой |
| `version`, `os`, `arch`, `electron`, `locale` | всегда | версия приложения и система |
| `message` | отзыв | то, что человек написал |
| `contact` | отзыв | заполненное поле «Куда ответить», необязательное |
| `log` | отзыв + галочка | журнал `%APPDATA%\OCD\logs\ocd.log`, обрезанный до 20 000 символов |

Ничего больше: ни путей к файлам пользователя, ни имён окон, ни переписки.
Отметка об установке не содержит ничего, кроме перечисленного выше, — это видно
в тесте `src/main/feedback.test.ts`.

---

## Границы защиты

- **URL — это пароль.** Apps Script не проверяет, кто шлёт POST. Ссылка попадает
  в exe каждого, кто скачает приложение, поэтому строки в таблице может
  добавить кто угодно. Не клади в отзыв ничего, что нельзя показать.
- **`doGet` читают те же люди.** Он отдаёт только счётчики; текст отзывов
  наружу не отдаётся.
- **Дубликаты отметок.** Сеть, оборванная после отправки, даст одну и ту же
  версию дважды: `marks` вырастет на 1, `uniqueInstalls` — нет. Для счётчика
  установок это неважно, для графика по версиям — слегка завышает.
