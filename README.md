# OCD — OpenCode Deck

Акриловое desktop-приложение для OpenCode на Windows 11: собственный чат, менеджер
плагинов, выбор провайдеров и гибкие настройки. Работает поверх фонового сервиса
OpenCode — то есть использует те же сессии, плагины и модели, что и штатный
OpenCode Desktop.

По умолчанию модель — `opencode/space-bunny-free`.

---

## Что умеет

**Чат**
- Полноценная работа с сессиями OpenCode: создание, переименование, удаление.
- Потоковый вывод ответов по SSE-событиям сервера (`session.text.delta` и т.д.).
- Блоки «Размышления» и вызовы инструментов — свёрнутые, с вводом и выводом.
- Несколько вкладок с сессиями, группировка по датам (Сегодня / Неделя / Месяц).
- Выбор модели и агента прямо в шапке чата, прерывание ответа, токены и стоимость.
- Модель фиксируется в сессии: серверный дефолт может быть недоступен в регионе,
  поэтому OCD всегда пинит выбранную модель и показывает реальную модель сеанса.

**Разметка и код**
- Ответ модели рендерится как Markdown: заголовки, списки, таблицы, цитаты, ссылки.
  Заголовки смещены на уровень ниже — `#` в пузыре чата выглядел бы криком.
- Подсветка синтаксиса через highlight.js, светлая и тёмная темы.
- Номера строк в блоках кода — через CSS-счётчики, а не по одному `<span>` на строку.
- Копирование кода в один клик; внешние ссылки уходят в системный браузер.
- Код-блоки ` ```html ` получают кнопку «Открыть в панели» — смотрите ниже.
- Автоопределение языка включается только когда текст похож на исходник: иначе
  обычная английская реплика уверенно помечалась как `vbnet`, и цвета врали.

**Панель предпросмотра**
- Справа от переписки: скрыта → открыта по кнопке → закреплена (переживает новый
  документ и смену сессии).
- Источники: fenced-блок ` ```html ` в ответе и любой файл, который создал агент.
- Форматы, которые Chromium рендерит сам: HTML, SVG, PNG, APNG, JPG, GIF, WebP,
  AVIF, BMP, ICO, MP4, WebM, MOV, PDF (встроенный просмотрщик с поиском и зумом).
- Word / Excel / PowerPoint / OpenDocument / RTF / CSV → LibreOffice конвертирует
  в PDF, вёрстка сохраняется.
- TIFF, PPM, TGA, JPEG 2000, EXR, PSD, PCX, DDS, HDR → ffmpeg растрирует в PNG.
- Конвертация кэшируется по времени изменения файла, временные копии чистятся
  через сутки.
- Если конвертера нет — понятное сообщение вместо ошибки.

**Безопасность предпросмотра**
- Гость — `<webview>` на выделенной партиции `persist:ocd-preview`; preload
  вешается на неё через `will-attach-webview`, поэтому ни один будущий webview
  его не унаследует.
- Наружу — только доверенный клик по ссылке `_blank`; `isTrusted` нельзя подделать
  из скрипта страницы. Проверка схемы — в главном процессе (`file:` и
  `javascript:` отклоняются).
- `allowpopups` не выставлен: гость не может открыть окно.

**Особенности протокола OpenCode, которые важно знать**
- `POST /api/session/{id}/prompt` не выполняет ход синхронно, а ставит его в inbox.
  Сообщение, отправленное во время активного хода, доставляется как *steer* —
  OCD предупреждает об этом, чтобы не казалось, что запрос пропал.
- Тело `prompt` запрещает неизвестные поля (`additionalProperties: false`):
  `model` там не принимается, модель меняется через `POST /api/session/{id}/model`.
- `agents` — массив объектов `{ name }`, а не строк.

**Плагины**
- Список реально загруженных плагинов (встроенные + локальные + npm).
- Установка из npm прямо из окна приложения.
- Подключение своих локальных плагинов из папки.
- Удаление плагина, показ папки в проводнике.
- Всё пишется в `plugins` массив `opencode.jsonc` с сохранением форматирования.

**Провайдеры и модели**
- Полный список провайдеров и моделей с сервера OpenCode.
- Статус авторизации, контекстное окно, признак reasoning.
- Поиск и фильтр, выбор модели по умолчанию.

**Возможности**
- Агенты, команды, навыки, MCP-серверы — в одном месте.

**Вложения**
- Вставка из буфера обмена (`Ctrl+V` с изображением) и кнопка вставки.
- Drag-and-drop файлов в любое место окна.
- Кнопки: изображение / любой файл.
- Изображения до 8 МБ уходят инлайн как `data:` URL, крупные и остальные файлы — по `file://`.
- Поддерживаются изображения, видео, аудио, документы (pdf, txt, md, json, csv) и любые другие файлы.

**Отправка и остановка**
- Кнопка отправки и кнопка остановки разделены: во время активного хода
  можно либо остановить его, либо отправить уточнение — оно доставляется как *steer*
  и попадает в текущий ответ.
- Если модель зависла и сервер не прислал ни завершения, ни ошибки,
  состояние «в работе» само сбрасывается через 5 минут.

**Голос и диктовка**
- Озвучивание ответов через `edge-tts` (голос `ru-RU-SvetlanaNeural` по умолчанию),
  офлайн-фолбэк — системный голос Windows (SAPI).
- Диктовка в поле ввода: запись с микрофона → `faster-whisper` (локально).
- Настройки голоса наследуются из ваших плагинов `oc-voice` / `oc-dictate`.

**Внешний вид**
- Настоящий системный акрил Windows 11 (`backgroundMaterial: "acrylic"`).
- Светлая тема в стиле Mica (как Проводник) и тёмная.
- Настройка плотности акрила, оттенка, акцента, размера шрифта.

## Требования

| Что | Зачем |
|---|---|
| Windows 11 22H2+ | системный акрил; на более старых окно будет полупрозрачным без размытия |
| OpenCode 2.x, запущенный как фоновый сервис | OCD подключается к нему по HTTP |
| Python 3 + `edge-tts`, `faster-whisper`, `sounddevice`, `numpy` | только для голоса и диктовки |
| `ffplay` (входит в полный fffmpeg build) | воспроизведение озвучки |
| `ffmpeg` | растеризация tiff/ppm/tga/jp2/exr/psd/pcx/dds/hdr |
| ImageMagick 7 (Q16) | **HEIC/HEIF/AVCI** — ни одна сборка ffmpeg из winget не содержит libheif |
| LibreOffice | doc/xls/ppt/odt/ods/odp/rtf/csv → PDF для предпросмотра |
| OpenSSH Client (входит в Windows 11) | туннель к удалённому OpenCode |

Без Python приложение работает полностью — голос просто отключится.

Установка Python-зависимостей:

```powershell
python -m pip install edge-tts faster-whisper sounddevice numpy
```

## Как OCD находит OpenCode

1. Читает регистрацию фонового сервиса:
   `$XDG_STATE_HOME/opencode/service.json` или `~/.local/state/opencode/service.json`
   (`{ id, version, url, pid, password }`).
2. Если сервис не отвечает — поднимает `opencode serve --service`,
   ищет бинарник в `PATH`, затем в `%APPDATA%\ai.opencode.desktop\cli\*\opencode-cli.exe`.
3. Авторизация — HTTP Basic (`opencode` + пароль из регистрации).
4. В адресной строке настроек можно указать свой адрес сервера.

Адрес можно открыть сразу на нужном экране: `OCD.exe` поддерживает
`#settings`, `#plugins`, `#providers`, `#capabilities`, `#chat`.

## Возможности

### Панель предпросмотра

Кнопка-куб в шапке чата (или «Открыть в панели» на блоке ```html) показывает документ
рядом с перепиской. Панель открывается сама, когда модель отдаёт HTML-блок или созданный файл.

Маршруты: нативно (HTML/SVG/изображения/видео/PDF) → LibreOffice → PDF → растеризация
(ffmpeg, затем ImageMagick). Результат кэшируется по времени изменения файла, чистится через сутки.

Гостевая страница грузится в <webview> на партиции persist:ocd-preview; preload вешается
только на неё. Внешние ссылки открываются в системном браузере и только по доверенному клику.

### Поиск по содержимому бесед

Сервер OpenCode не имеет поиска, поэтому индекс строится на стороне OCD: сообщения всех сессий
читаются один раз и складываются в ocd-search-index.json рядом с настройками. Поиск по названию
мгновенный, по тексту — с задержкой 180 мс. Совпадения показываются отдельным блоком с фрагментом.

Индекс пересобирается при изменении сессии; удалённые сессии из него выбрасываются.

### Трей, горячая клавиша, окна сессий

- Трей: показать/скрыть, быстрый запрос, недавние сессии, статус сервера, перезапуск,
  язык интерфейса, HUD, выход. Всё переведено на 5 языков.
- Глобальная горячая клавиша (по умолчанию выключена, задаётся в настройках) показывает окно
  и ставит курсор в поле ввода. Занятая другим приложением клавиша сообщается честно.
- Любую сессию можно открыть в отдельном окне: #session/<id>, одно окно на сессию.

### Экспорт беседы

Markdown, HTML и PDF. Инструменты сворачиваются в строки вида цитаты с названием команды,
рассуждения отбрасываются — в экспорте остаётся разговор, а не журнал. PDF печатается
скрытым offscreen-окном.

### Панель задач

Читает чекбоксы из последнего ответа модели и показывает прогресс. Это отображение плана,
а не отдельный список: разойтись с текстом модели он не может.

### HUD

Небольшая полоска поверх окон: что модель делает прямо сейчас. По умолчанию выключена,
включается из трея или настроек. Состояние собирает main и передаёт в окно HUD.

### Удалённый OpenCode по SSH

Настройки → «Удалённый сервер (SSH)»: хост в формате user@host и порт OpenCode на сервере.
Приложение поднимает туннель системным OpenSSH и переключает сервис на локальный порт.
Пароли не передаются: используются ваш ~/.ssh/config и ssh-agent.

### Расход, уведомления, правки

- **Расход** — стоимость и токены в шапке беседы, раскрываются кликом. Считается и по
  сохранённой истории, и в реальном времени через событие `session.usage.updated`.
- **Уведомления** — Windows-toast, когда ход закончился, пока окно свёрнуто. Плюс мигание
  панели задач. Отключаются в настройках.
- **Правка промпта** — кнопка «Изменить» на своём сообщении возвращает текст в поле ввода.
  Удалить сообщение и перезапустить ветку нельзя: сервер не даёт такой API (DELETE по
  сообщению и все разумные маршруты revert отвечают 404).
- **Фильтр инструментов** — по умолчанию показывает только неуспешные и текущие вызовы,
  остальные сворачивает в строку со счётчиком.
- **Черновики** — неотправленный текст хранится по беседе и переживает закрытие вкладки.
- **Закрепления и заметки** — важные ответы и своя заметка по беседе, локально, модель их
  не видит. Переживают перезапуск.

### Командная палитра

Ctrl+K — команды и беседы в одном списке. Поиск по названию и по словам-подсказкам,
стрелки и Enter.

### Перенос сообщений

Кнопка на сообщении копирует обмен в буфер с меткой; в целевой беседе Ctrl+V подставляет
её в поле ввода. Сервер не умеет двигать сообщения, поэтому текст остаётся под контролем
пользователя.
### Автообновление

Выключено по умолчанию. electron-updater только проверяет наличие версии; скачивание
начинается по вашему решению, установка — при следующем обычном выходе. Работает
только в установленной сборке.

### Как выпустить релиз

Канал обновлений — GitHub Releases репозитория `Sergey35853/ocd`.

```bash
npm version patch              # 0.1.0 -> 0.1.1: коммит + тег
git push origin main --follow-tags
```

Тег `v*` поднимает `.github/workflows/release.yml`: сборка на `windows-latest` и
публикация в релиз. electron-builder кладёт рядом `latest.yml` и `.blockmap` — без
них установленная копия обновление не найдёт, поэтому руками релиз не создаём.

Локально (когда CI не подходит) — то же плюс токен в `GH_TOKEN`:

```bash
npm run dist
```

Подпись сборок не настроена: каждый новый установщик вызывает предупреждение
SmartScreen. На само автообновление это не влияет. Portable-сборка
(`OCD-portable-*.exe`) не обновляется — только установщик NSIS.

## Настройки

Хранятся в `%APPDATA%\OCD\ocd-settings.json`.

Конфигурация OpenCode — `~/.config/opencode/opencode.jsonc`.
Редактор в приложении делает резервную копию `.ocd-backup` и проверяет JSON перед записью.

```
src/
  main/        Electron main: окно, акрил, трей, IPC
    service.ts     подключение к OpenCode, HTTP-клиент, SSE-поток событий
    ipc.ts         обработчики IPC, озвучивание ответов по событиям
    plugins.ts     менеджер плагинов (config + runtime)
    npm.ts         поиск плагинов в реестре npm
    configFile.ts  безопасное чтение/запись opencode.jsonc (jsonc-parser)
    voice.ts       TTS + диктовка через resources/voice.py
    settings.ts    настройки приложения
    preview.ts     конвертация документов для панели предпросмотра
    export.ts      экспорт беседы в Markdown / HTML / PDF
    searchIndex.ts полнотекстовый индекс бесед на диске
    sshTunnel.ts   туннель к удалённому OpenCode через системный OpenSSH
    hud.ts         отдельное окно-индикатор поверх окон
    tray.ts        меню трея со состоянием
    windows.ts     окна сессий и глобальная горячая клавиша
    updater.ts     проверка обновлений (electron-updater)
    icon.ts        иконка окна и трея
    i18n.ts        строки главного процесса (трей, диалоги)
  shared/      типы и карта поддерживаемых форматов
  preload/     contextBridge + отдельный preload для гостя предпросмотра
  renderer/    React UI (index.html — основное окно, hud.html — индикатор)
resources/
  voice.py     edge-tts + faster-whisper + sounddevice
  icon.png
```

## Безопасность

- `contextIsolation: true`, `nodeIntegration: false`, весь доступ к диску и сети — через IPC в main.
- Открытие внешних ссылок только для `http(s)`.
- Правка `opencode.jsonc` — с валидацией и бэкапом.
- Markdown рендерится с `html: false`, а единственное место, где в DOM попадает
  разметка — подсветка, и там текст экранируется заранее.
- Гость предпросмотра изолирован партицией и не имеет доступа к IPC.

## Зависимости

Встраиваются в `node_modules`, поставляются вместе с exe:

| Пакет | Зачем |
|---|---|
| `markdown-it` | Markdown-рендер ответов |
| `highlight.js` | подсветка синтаксиса |
| `jsonc-parser` | правка `opencode.jsonc` без потери комментариев |

Внешние программы для предпросмотра (не обязательны):

| Программа | Зачем | Без неё |
|---|---|---|
| LibreOffice | Word / Excel / PowerPoint → PDF | сообщение «не найден LibreOffice» |
| ffmpeg | TIFF, PSD, JPEG 2000 и прочие → PNG | сообщение «не найден ffmpeg» |

Пути к обоим перебираются в стандартных местах установки и в `PATH`; положите
`ffmpeg.exe` в `PATH`, если он установлен нестандартно.
